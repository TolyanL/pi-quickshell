# pi-quickshell

Индикатор сессий pi для Linux и локального бара QuickShell (`BarButton` и `Theme`). На панели — общий статус, по наведению — сессии и их активные сабагенты `@tintinweb/pi-subagents`. Сессия подписана её именем или именем каталога проекта. Статусы по приоритету: `error` > `asking` > `working` > `idle`. Если сессий нет, кнопка остаётся серой, список пуст.

`asking` означает открытый UI-запрос pi или выполняющийся `ask_user_question`, а не вопрос в тексте сообщения. Для дочерних агентов публичная шина сообщает запуск и завершение, но не UI-запросы. Успешные и остановленные дочерние агенты исчезают; последняя ошибка остаётся до следующего запуска основного агента или повторного запуска этого сабагента.

## Подключение

Из каталога пакета:

```sh
pi install "$PWD"
ln -s "$PWD/PiAgents.qml" ~/.config/quickshell/modules/PiAgents.qml
ln -s "$PWD/pi-agents.py" ~/.config/quickshell/scripts/pi-agents.py
```

Добавить `PiAgents {}` в `modules/Bar.qml`, выполнить `qs ipc call shell reload`. В уже открытых сессиях pi выполнить `/reload`. Нужны Python 3 и версия pi с `agent_settled` и `ui_prompt_start/end`.

Состояние хранится в `$XDG_RUNTIME_DIR/pi-quickshell/<pid>.json` (каталог `0700`, файл `0600`), без промптов и результатов инструментов. Виджет читает его раз в секунду. После аварийного завершения читатель отбрасывает старую запись по PID и времени старта процесса в `/proc`.

Проверка: `npm test` (Node с поддержкой TypeScript) и `python3 pi-agents.py` для просмотра данных панели.
